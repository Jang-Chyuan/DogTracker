# 共用固定位置設定

> **App 端已移除**：狗在室內時改成停在最後清楚的位置，不再畫在設定點，詳細資訊裡也沒有「固定位置設定」表單了（見 [src/placement/README.md](../src/placement/README.md)）。Supabase 的資料表、解鎖函式與 migration 保留，舊資料不會遺失；要恢復 App 端，revert 這次的變更即可，既有設定會照舊生效。以下是原本的說明，留作後端參考。

先在現有 Supabase 專案套用 `supabase/migrations/202610040001_slave_fixed_locations.sql`。
此分支不會自動修改線上資料庫。

手機登入雲端帳號後，在即時地圖的狗清單／marker 開啟詳細資訊，向下捲至「固定位置設定」。
輸入名稱、十進位緯度與經度、啟用狀態，再按「儲存固定位置」。
未登入時顯示登入提示；讀取失敗提供重試；上傳失敗保留輸入並顯示尚未同步。

每隻 slave 只有一筆設定，以 `slave_id` 為唯一鍵。初次儲存以狗目前回報的 Master 為授權範圍；
既有設定沿用原 Master。同一 Master 的所有授權成員都可讀寫，不限同一個帳號。
其他手機開啟詳細資訊會讀取伺服器最新設定；已開啟的表單需關閉後重開。
同時編輯採最後成功寫入者為準。RLS 沿用 device_members 的 Master 級授權，不套用 slave_id 篩選。
會員關係由管理員維護；本功能不提供自行新增會員。跨 Master 共用需另外設計團隊／狗授權。

前景每 10 秒讀取有權存取的固定設定；同一 App 執行期間斷網保留該帳號最後成功快照，
重新啟動後需連網下載，尚未實作磁碟離線快取。帳號切換不顯示其他帳號的設定。

即時地圖：最新有效封包 USB 已連接優先標示「充電（USB 已連接）」；否則使用最近
已完成分鐘的 ML 判斷，室內或窗邊結果超過 2 分鐘即不套用。停止通訊時依 3 分鐘
有效期排除 marker。USB 接入不保證電池實際正在充電。

即時 slave 地圖改以最後收到封包判斷：超過 3 分鐘未收到才隱藏；持續收到無定位封包
時保留最後有效座標並標示最後位置。ML 分類有效期仍為 2 分鐘。

充電為例外：最近 USB 已接入，或 ML 的 usb_rule 結果且未收到明確拔除封包時，
維持固定位置，不因 3 分鐘無封包而隱藏，仍標示未收到新資料。資料來源仍受 24 小時
保留範圍限制；不是無限期鎖定。明確 USB=0 解除充電保留，恢復一般環境／GPS 規則。

歷史：依封包當時 USB 與前一個已完成分鐘的模型結果套用；查詢前多讀 2 分鐘提供判斷上下文。
固定位置與 GPS 切換時斷線，避免畫出假的移動路線。地圖 marker、狗清單與詳細資訊標示原因。
使用目前設定回算歷史，修改位置會重新顯示過去軌跡；此表尚無版本歷程。
原始 GPS、資料庫封包、匯出資料與 ML 輸入保持原始資料；只更換地圖顯示座標。

驗收：兩個具有同一 Master 權限的帳號可互相讀取儲存結果；未授權帳號不能讀寫；
空白／超出範圍座標不能提交；斷網提交顯示失敗且保留輸入。
